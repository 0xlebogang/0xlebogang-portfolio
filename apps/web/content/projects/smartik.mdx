> The project was being developed as part of a hackathon solution where specific challenges were to be addressed within a limited timeframe. Unfortunately, we weren't selected to proceed to the next stage where we were to complete the project and present it to potential investors. As a result, the team got demotivated and the project got abandoned. We have spoken and plans to finish off the project are in order. It'll be completed, but with more student developers onboarded as part of the development team, probably over the next year.

## Project Overview

Smartik is an innovative automated script marking system designed to streamline the evaluation process for matric examinations. By leveraging cutting-edge technologies, Smartik provides educators with a reliable and efficient tool to assess student performance, ensuring accuracy and consistency in grading. Additionally, Smartik aims to reduce the administrative and financial burden on the eduction system by minimizing the need for manual script marking. Lots of time gets saved in the process.

## My Role

I took on the role as lead developer, project manager and API developer, spearheading the development of Smartik from conception to implementation. My responsibilities included designing the system architecture, overseeing the integration of various technologies, and ensuring that the project met its objectives within the stipulated timeframe. I collaborated closely with the team, ensuring that Smartik addressed the specific challenges faced in script marking.

Although the project was not completed, the API currently has fully functional CRUD operations for managing the scripts, students and exams. You can find the code in [`services/api`](https://github.com/0xlebogang/smartik/tree/main/services/api).
